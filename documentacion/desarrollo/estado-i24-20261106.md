## Criterio para cerrar I24

El piloto **no está aceptado operativamente**. Requiere un workshop con dos sesiones/cajas Electron operables, administrador y central, periféricos reales o virtuales definidos, y credenciales de homologación/sandbox vigentes. Registrar por caso hora, caja, usuario, resultado y evidencia; contrastar cobros/CAE/stock en la API y la base autorizada. Una venta o cobro de prueba debe quedar identificado para conciliación; no borrar operaciones comerciales históricas. PEND-01/PEND-02 de balanzas en construcción permanecen excluidos.
