# Interfaz Angular de Carnicerías

Esta aplicación se utiliza dentro de Electron para el puesto de venta y como base de las pantallas web. El estado y los contratos del producto están documentados en el [README principal](../../README.md), `tasks/pos-todo.md` y los archivos `SPEC-*.md` de la raíz.

Los scripts de este paquete son `npm run start`, `npm run build`, `npm run lint` y `npm test -- --watch=false`. Para revisar el POS se debe abrir con `npm run electron:start --prefix src/Carnicerias.Pos` desde la raíz, no usar el navegador como sustituto de la verificación en Electron.
